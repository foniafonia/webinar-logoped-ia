# Cuaderno Rub-IA v2

App web de grafomotricidad/disgrafia con:

- Efecto de libro con paso de pagina
- Paginas predefinidas (estilo cuaderno terapeutico)
- Justificacion teorica en cada seccion
- Editor creativo: el terapeuta escribe silabas/palabras y se genera una pagina
- Impresion directa en A4 o guardado como PDF desde el navegador
- Presets pedagogicos por tramo de edad/intervencion
- Pauta configurable: montessori/trilinea, cuadricula o linea simple
- Parametros tecnicos: x-height, ratio ascendente y ratio descendente
- Calco punteado en SVG (escalable para impresion)

## Uso

1. Abre `index.html` en tu navegador.
2. Navega con `Anterior` / `Siguiente` o flechas del teclado.
3. En `Editor del terapeuta`, escribe texto como:
   - `MA ME MI MO MU`
   - `PUASO QUESA TIRLO`
4. Pulsa `Generar pagina personalizada`.
5. Pulsa `Imprimir / PDF` para sacar el cuaderno.

## Nota

Material de entrenamiento inspirado en secuenciaciones clasicas de caligrafia/grafomotricidad, sin afiliacion con marcas externas.
